# Instructions: GitLean Ongoing Logs

## Ongoing Tasks during Development
As we build GitLean, we must maintain two logs in real time:

1. **`feedback.md`**: For the **Most Valuable Feedback Prize**.
   - Any bug, odd behavior, validation gap, or limitation we discover in Paritok's API, proxy server, or documentation must be immediately documented here.
   - Include: Endpoint probed, input sent, expected behavior, actual behavior, and suggested fix.

2. **`social_media.md`**: For the **Social Blitz Prize**.
   - Write short, punchy X (Twitter) posts as new features of GitLean are implemented.
   - Include code highlights, screenshots prompts, and explanations of how Paritok is saving tokens.
   - Always tag with `#BuiltWithParitok`.

## Critical Rule
Whenever a new component or backend functionality is added, the agent MUST review and append relevant findings to both `feedback.md` and `social_media.md`.
